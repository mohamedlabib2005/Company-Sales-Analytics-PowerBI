#  Company Sales Analytics - Power BI

##  Project Overview

An interactive Power BI dashboard built to analyze company sales performance and provide insights into orders, revenue, products, territories, and order status.

##  Key Insights

The dashboard analyzes:

-  Total Orders
-  Total Order Details
-  Total Due
-  Total Freight
-  Total Quantity
-  Total Tax
-  Sales trends by year
-  Top-selling products
-  Sales by product category
-  Sales by territory
-  Orders by status

## Data Model

The project uses a dimensional data model with:

- Fact Sales
- Dim Product
- Dim Territory
- Dim Status
- Dim Ship Method
- Dim Ship Date
- Dim Due Date
- Dim Order Date
